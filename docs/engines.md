# Рушії: план робіт

Записано 28.10.2026. Ідея — у `docs/concept.md`; тут — що в якому порядку робиться і що вже зроблено.
Тексти інтерфейсу й описи нейтральні: кажуть, що програма робить, і ніколи — де працює рушій.

## Фаза 0 — шов для другого рушія розшифровки

> **Зроблено 28.10.2026.**

Модель і воркер виїхали з `App.tsx` у `src/useWhisper.ts`. Назовні — стан моделі (для рядка статусу, вікна
згоди й налаштувань) і `transcribe(samples, language, handlers)`, що повертає `Promise<{ text, segments } | null>`
(`null` — прогін зупинено або GPU впав, і повідомляти нема чого). `App.tsx` тримає тільки сам прогін: читання
звуку, `job`, текст, продовження після зупинки. Хмарний рушій у фазі 2 дає ту саму сигнатуру `transcribe`.

## Фаза 1 — конспект і таймкоди через API

> **Зроблено 28.10.2026.**

- Один адаптер: OpenAI-сумісний `POST {baseUrl}/chat/completions`. Покриває OpenAI, OpenRouter, Groq, DeepSeek,
  ollama, LM Studio, llama.cpp, vLLM. Чисті функції — `src/api.ts` (тест `src/api.test.ts`), запит — `net.fetch`
  у main (`src/summary.ts`), тож `ai:run`, промпти й скасування ті самі.
- Налаштування рушія живуть у main (`engines.json` у `userData`), не в localStorage. Ключ шифрується через
  `safeStorage` і назад у renderer не йде — той знає лише «ключ є».
- Зміна Base URL стирає збережений ключ: інакше renderer міг би перенаправити чинний ключ на чужу адресу.
- Без системного сховища ключів (`safeStorage` на `basic_text`) ключ не зберігається взагалі — помилка, а не
  тихе збереження відкритим текстом.
- `https` обов'язковий; `http` — лише для `localhost` / `127.0.0.1` / `[::1]`.
- За замовчуванням лишається `claude` CLI; API вмикається явним вибором у налаштуваннях.

## Фаза 2 — хмарна розшифровка

- Той самий адаптер: `POST {baseUrl}/audio/transcriptions`, запит із main, результат → `Segment[]`.
- **Перевірити перед стартом:** хто з провайдерів віддає сегменти з таймкодами (`verbose_json`). Без них немає
  .srt і розділів. За памʼяттю — `whisper-1` в OpenAI так, `gpt-4o-transcribe` ні; Groq `whisper-large-v3` так.
- Ліміт 25 МБ на запит. OGG/Opus з `exportAudio` — ≈10 МБ на годину мови, тобто до ~2 годин одним запитом.
- 2б: нарізання довших файлів (і WAV без ffmpeg) по тиші — мінімум RMS біля межі шматка, зсув таймкодів на
  зміщення. Чиста функція з тестом.
- Прогрес — за готовими шматками; інгібітор сну й скасування — як у воркера.

## Фаза 3 — інтерфейс

- Вибір рушія розшифровки в налаштуваннях поруч із рушієм конспекту; пресети провайдерів; кнопка «Перевірити».
- Перший запуск: у вікні згоди на модель — друга гілка «вставити ключ».

## Не вирішено

- Нативний Anthropic Messages API (другий адаптер) — поки ні; OpenRouter покриває через OpenAI-формат.
- Deepgram.
- Чи отримує командний рядок (`--transcribe`) хмарний рушій.
